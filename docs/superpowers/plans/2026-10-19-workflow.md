## Verification boundaries

Graph: exactly one entry; all nodes reachable along one normal chain; no ambiguous exits or normal cycles; only review return edges to earlier agent cards, with finite limits; validate all execution fields at Start and all input shapes on save.

Executor: actual edges drive order; retain current early results, invalidate downstream results on return; stop for missing output/invalid verdict/needs_input; at most N returns; human review pauses and acceptance completes only the run. Hold one canonical working-directory lease throughout an active run. Persist before launching or publishing; on restart require explicit reconciliation/resume.

Adapters: require protocol completion and nonempty output; validate declared files; never infer success from terminal idleness. Fresh review sessions. Git must start clean for code/publication, freeze branch and remote, capture content before review, reject review-time or post-review edits, and reconcile commits/push/MR after uncertain responses.

UI: save nodes, edges and viewport; drag/pan/zoom/fit; execution settings lock for active snapshots; errors identify nodes/edges. Shared terminal remains below the web view; opening logs is explicit. Persist UI selection across web view recreation.
